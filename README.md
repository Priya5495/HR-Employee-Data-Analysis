
# HR Employee Data Analysis – Excel 

## Project Description
This project focuses on analyzing an HR Employee Dataset using Microsoft Excel 2016. The dataset contains employee information, including Employee ID, Joining Date, End Date, Date of Birth, Work Start Time, Work End Time, Tenure, Employment Status, Daily Working Hours, Joining Year, Joining Month, Joining Weekday, and Employee Age.

The objective of this project is to practice Excel date and time functions, data calculations, and basic HR analytics.

## Dataset Details
The dataset includes the following columns:
- Employee ID
- Join Date
- End Date
- Birth Date
- Work Start Time
- Work End Time
- Tenure (Years, Months, Days)
- Employee Status (Active/Inactive)
- Working Hours per Day
- Joining Year
- Joining Month
- Joining Weekday
- Employee Age

## Excel Functions & Concepts Used
- **DATEDIF** – To calculate employee tenure in years, months, and days.
- **IF** – To identify employee employment status.
- **HOUR / TIME calculations** – To calculate daily working hours.
- **YEAR** – To extract the joining year.
- **MONTH** – To extract the joining month.
- **TEXT** – To identify the weekday of joining.
- **DATEDIF** – To calculate employee age.

## Project Objectives
1. Understand and organize HR employee data.
2. Calculate employee tenure and age.
3. Identify active and inactive employees.
4. Calculate daily working hours.
5. Extract useful information from employee joining dates.
6. Develop practical Excel skills for HR Data Analytics.

## Tools Used
- Microsoft Excel 2016
- Excel Formulas and Functions

This project helped me gain practical experience in handling HR datasets, applying Excel formulas, calculating employee-related metrics, and understanding how Excel can be used for basic HR analytics.
